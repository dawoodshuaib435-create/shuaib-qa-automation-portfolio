# Shuaib Dawood — QA Automation Portfolio

A hands-on personal QA project demonstrating:
- Manual, functional and regression testing
- Playwright UI automation
- Robot Framework automation
- Postman API testing
- SQL validation
- Defect reporting and traceability

> This is a personal portfolio project, not commercial production experience.

## Target role
Intermediate QA Tester — Amaris Consulting

## Test applications
- SauceDemo: https://www.saucedemo.com/
- ReqRes API: https://reqres.in/

## Run Playwright
```bash
npm install
npx playwright install
npm test
npm run report
```

## Run Robot Framework
```bash
pip install -r robot/requirements.txt
robot robot/tests
```
