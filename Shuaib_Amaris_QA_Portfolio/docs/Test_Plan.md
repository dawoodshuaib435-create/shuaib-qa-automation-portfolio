# Test Plan — SauceDemo

## Objective
Validate the highest-risk customer journeys and demonstrate a balanced manual + automated QA approach.

## In scope
- Authentication
- Inventory
- Shopping cart
- Positive and negative scenarios
- Core regression

## Automation candidates
- Valid login
- Invalid login
- Locked user
- Add/remove cart item

## Exit criteria
- All P1 scenarios executed
- No open critical defects
- Regression results documented
