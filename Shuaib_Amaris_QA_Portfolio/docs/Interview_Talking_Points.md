# Amaris Interview Talking Points

## Portfolio explanation
“My professional background has been strongest in manual, functional, regression and API testing across web and multiple device platforms. I built this portfolio to strengthen my automation capability using Playwright, Robot Framework, Postman and SQL.”

## Automation wording
Do not claim commercial years of Playwright, Robot Framework or Selenium.

Use:
“I have hands-on automation project experience and a strong professional manual/API QA foundation. I am actively expanding my automation depth.”

## If a developer cannot reproduce a bug
Confirm environment/data/version, reproduce again, minimise steps, attach evidence and isolate whether it is UI, API, data or environment related.

## API is 200 but UI is wrong
Compare API payload with UI, inspect network calls, validate mapping/transformation and check data source where possible.
