# Sample Defect Report

**ID:** BUG-001  
**Title:** Cart badge count does not update after removing the final item  
**Severity:** Major  
**Priority:** P1  

## Steps
1. Log in.
2. Add one item.
3. Open cart.
4. Remove the only item.
5. Observe cart badge.

## Expected
Badge disappears or updates immediately.

## Actual
Badge still shows `1` until refresh.

## Evidence
Attach screenshot/video/logs.
