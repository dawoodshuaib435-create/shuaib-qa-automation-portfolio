# QA Strategy Notes

## Automate
Stable, repeatable, high-risk regression scenarios.

## Keep manual
Exploratory, usability, rapidly changing or highly visual checks.

## Defect workflow
Reproduce → isolate → capture environment → exact steps → expected vs actual → evidence → retest → regression.

## API validation
Status code, payload, required fields, business rules, negative cases and error handling.

## SQL validation
UI/data reconciliation, duplicates, referential integrity, totals and state transitions.
